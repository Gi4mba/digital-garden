# Layout markers (Quartz 5 default build)

Class names that must NOT appear in the HTML of the garden. Verified against a default build of a content page.

- Explorer: `explorer`
- Graph: `graph`
- Backlinks: `backlinks`
- Search: `search`
- TOC: `toc`
- Breadcrumb: `breadcrumb-container`
- Popover hint wrapper: `popover-hint`
- Theme toggle: `darkmode`
- Reader mode: `readermode`
- Sidebar title/links: `page-title`, `left sidebar`, `right sidebar`
